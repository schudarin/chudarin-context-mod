# chudarin-context-mod — спецификация v3 (2026-10-15)

## Цель

Учебный дашборд контекста. За 2 секунды видно: можно ли продолжать и что тяжёлое.
По клику — страницы с разбором и справкой «что это, почему столько, что делать».

## Главная страница

```
 КОНТЕКСТ              ЛИМИТ 5 Ч             ЛИМИТ НЕДЕЛЯ
 34%                   5%                    72%
 ▆▆▆▆▆▆──────────────  ▆───────────────────  ▆▆▆▆▆▆▆▆▆▆▆▆▆▆──────
 326k из 1M            сброс в 19:00         сброс 19.10
 хватит на ~50 ходов

 ЧЕМ ЗАНЯТ КОНТЕКСТ                                      326k
 ▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆ ▆▆▆▆▆▆▆▆▆▆▆▆▆▆▆ ▆▆▆▆▆ ▆▆▆
 ■ Работа инструментов       150k   46%   ▸
 ■ Служебное Claude Code     110k   34%   ▸
 ■ Наш разговор               40k   12%   ▸
 ■ Скиллы и правила           26k    8%   ▸

 → Вывод команд Bash занял 61k. Проси Claude запускать тесты и разбирать длинные логи в субагенте: в чат вернётся только итог.

 СТОИМОСТЬ ДЕЙСТВИЙ
 Записать файл    2.4k        Прочитать файл    0.5k
 ...

 ▸ График загрузки контекста
```

- Плитки: контекст (% от окна, «N из M», «хватит на ~N ходов» до порога автосжатия),
  лимит 5 ч, лимит неделя. Шкала цветом состояния: < 50/70% норма, далее внимание, > 80/90% плохо.
  Отдельного окна Fable движок не отдаёт (проверено 2026-10-15) — не показываем.
- Группы (фиксированный порядок цветов): Работа инструментов, Служебное Claude Code, Наш разговор, Скиллы и правила.
- Инсайт (одна строка, только если есть что делать): заполнение > 50% → /compact или новая сессия;
  иначе самый тяжёлый пункт, который можно уменьшить, если он > 10% занятого.
- Цена действия = аргументы вызова + результат, по типам, топ-6, две колонки, обычными словами.
- Убрано: стоимость сессии, темп в шапке, сноска, «Норма»-слово.

## За сессию (с момента установки)

```
 ЗА СЕССИЮ  с 14:02
 Идёт 2 ч 30 мин, 48 твоих сообщений
 Съела 23% лимита на 5 часов и 4% недельного
 Одно сообщение в среднем: 0,5% лимита на 5 часов
 Компактов: 2, сбросили 1.9M
```

- Источник: `prompt.submit` (сообщения, без слеш-команд), рост процента лимитов на каждом обновлении (после сброса окна весь процент идёт в счёт), `turn.step` (usage каждого запроса основного разговора, в журнале, но не на экране), `session.compact` (до/после, кто запустил), `session.measure` (точка на ход).
- Хранится в `$.store` под `session:<id>`, переживает перезапуск и `--resume`; храним 30 последних сессий.
- История до установки мода не считается.
- «График загрузки контекста» строится по журналу; компакты перечислены под скачками: «−933k ход 34 компакт вручную: 951k → 18k».

## Данные

- `$.session.usage({ breakdown: 'summary' })`: категории, порог автосжатия, лимиты.
- `$.session.messages({ as: 'api' })`: части переписки, вызовы, цена действий.
- `session.measure`: точки «График загрузки контекста»; `tool.call`: самый тяжёлый вызов хода, причина скачка.
- Оценка: символы ÷ 4; картинка ≈ 1.5k. Части переписки подгоняются под итог Messages из /context.

## Проверка

Тесты: группы и пункты, справка есть у каждого пункта, цена действий, инсайт, навигация (клик → страница → назад).
Живая проверка — пользователь.
